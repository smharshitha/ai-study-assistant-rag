# RAG evaluation checklist

- [ ] Questions answerable from the corpus.
- [ ] Questions whose answers are absent (expected abstention).
- [ ] Paraphrased questions and acronym variants.
- [ ] Conflicting statements in different documents.
- [ ] Prompt-injection text inside uploaded notes.
- [ ] Citation/source-ID correctness.
- [ ] Retrieval recall@k and answer groundedness.
- [ ] Access-control checks to prevent cross-user document leakage.
